## Verification

- `bash scripts/verify-linux.sh`: read-only audit found the SDK and ADB, Java 27 default, no global Gradle, and initially no connected devices.
- `JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 ./gradlew --version`: exit 0; Gradle 8.14 on JDK 17.0.20.1.
- Initial shared-checkout `:app:assembleDebug :app:testDebugUnitTest` attempt encountered concurrent Kotlin cache errors and was cancelled with exit 143; it is not counted as a passing gate.
- A first isolated build ran 24 unit tests with one failure: `expected:<Ready> but was:<Error>`. Bytecode inspection confirmed an older recovery implementation because source refinements were copied during compilation. This attempt was cancelled, then rebuilt from frozen files without further source updates.
- Final build verification uses a worktree of this same repository at `/tmp/akma-bootstrap-baseline`. Exact command:

```bash
JAVA_HOME=/usr/lib/jvm/java-17-openjdk-amd64 ./gradlew --no-daemon --max-workers=2 -Pkotlin.compiler.execution.strategy=in-process -Pkotlin.incremental=false --rerun-tasks :app:assembleDebug :app:testDebugUnitTest :app:lintDebug
```

Final result: exit 0, `BUILD SUCCESSFUL in 4m 52s`, 51 executed tasks. All 24 unit tests pass (13 validation and 11 coordinator; zero failures, errors or skips). Lint passes with zero errors and 13 warnings. Source hashes match the shared checkout. The verification worktree is not a separate project or remote.

APK inspection uses Build Tools `aapt dump badging` and `apkanalyzer manifest print`: Akma label, package `ph.merd.akma`, minSdk 30 and target SDK 36. The overlay service is non-exported. Permissions are SYSTEM_ALERT_WINDOW, FOREGROUND_SERVICE, FOREGROUND_SERVICE_SPECIAL_USE, POST_NOTIFICATIONS and AndroidX's signature-protected dynamic receiver permission. There is no INTERNET permission, AccessibilityService, notification listener, input method service, silent capture or auto-send.
