# Windows 11 Pro 25H2 — PowerShell (no WSL required)

Run PowerShell in repo root:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\scripts\verify-windows.ps1
```

If missing, install using official tooling or `winget` **only for items needed by the selected stack**:

```powershell
winget install --id Git.Git -e
winget install --id GitHub.cli -e
winget install --id Google.AndroidStudio -e
```

Verify Git, GitHub CLI, Android Studio SDK, `adb`, Java and USB drivers; only enable USB debugging on your authorized devices. Do not blindly upgrade a working Android Studio/JDK installation. Use Android Studio's SDK Manager for Android SDK platforms, platform-tools and (if llama.cpp JNI chosen) NDK/CMake.

```powershell
gh auth status
adb devices -l
.\gradlew.bat --version
.\gradlew.bat --no-daemon assembleDebug testDebugUnitTest
adb install -r app\build\outputs\apk\debug\app-debug.apk
```

The Gradle wrapper is generated by bootstrap agent; it does not exist in docs-only starting snapshot. PowerShell script execution policy can be restrictive; use per-process `-ExecutionPolicy Bypass` only for the reviewed local audit script, not permanent machine-wide changes. Use Git Bash or PowerShell consistently for shell scripts; don't copy Bash env syntax into PowerShell.

For Spec Kit: install supported Python 3.11+ and uv, then `uv tool install specify-cli`; check `specify --help`, use `--script py` if supported for a common script across OSes. Install Matt Pocock skills into the desired agent separately after reviewing installed skills.
