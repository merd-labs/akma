# Infinix Zero 5G (X6815B): Gemma 4 E2B on-device smoke test, 2026-10-10

**Scope:** one real-engine release build, sideloaded model, driven over ADB on Rhence's handset. This is a smoke test, not a benchmark. Items not listed under "Observed" are **NOT MEASURED / NOT TESTED**.

## Handset (read with `getprop` / `dumpsys`)

| Item | Value |
|---|---|
| Model | Infinix X6815B (`product:X6815B-OP`) |
| Android | **12, API 31** (earlier team docs said Android 11 / API 30; this unit reports 12) |
| `MemTotal` | 7,805,584 kB (about 150 MB `MemFree` at idle; the rest was cache) |
| `/data` free | about 56.3 GB of 113 GB |
| Battery | 94-95 %, USB powered, 30.1 C (`dumpsys battery` temperature 301) near the end of the run |

## Build and install

- `./gradlew :app:assembleRelease` (real `LiteRtReplyEngine`; debug builds use the demo engine and prove nothing). The release variant has no signing config, so the APK was `zipalign`ed and signed with the local Android debug key for this test only. The signing key and APK are not committed.
- APK without model: 74 MB, SHA-256 `de9f10c99ad99599f9bad9427fbdb80fb96270b99496b99de682a3c78cb33a8d`.
- `adb install -r -d` updated the existing `ph.merd.akma` in place (same signer, no uninstall, no data wipe).

## Model sideload

- `adb push gemma-4-E2B-it.litertlm /sdcard/Android/data/ph.merd.akma/files/models/`: 2,588,147,712 bytes in 70.0 s (35.2 MB/s). Writing to app-scoped external storage from `adb shell` worked on this Android 12 unit.
- On-device `sha256sum` equals the pin: `181938105e0eefd105961417e8da75903eacda102c4fce9ce90f50b97139a63c`.
- The app's automatic model check ran at first launch, before the push finished, and showed the typed error "The bundled model is missing. Install the verified model-enabled Akma APK." After the push, **Try again** loaded the model. (The wording still says "bundled"; see Follow-ups.)

## Observed

Five generations were recorded by the `AkmaInference` log tag (durations and character counts only), airplane mode on (status-bar icon visible in the screenshots):

| # | `generation_ms` | `first_text_ms` | chars |
|---|---|---|---|
| 1 | 7,366 | 4,600 | 110 |
| 2 | 6,302 | 3,050 | 117 |
| 3 | 6,185 | 3,227 | 97 |
| 4 | 4,802 | 3,134 | 57 |
| 5 | 5,502 | 2,968 | 58 |

Mean generation 6.0 s (range 4.8-7.4 s); first text 3.0-4.6 s. Runs 1-4 were started by people using the handset at the same time as the ADB session, so their language, action and raw text were not captured. Run 5 was started over ADB.

- **Taglish draft (run 5):** message `Hello po, pwede ba tayong mag-meeting bukas ng 3 PM about sa project`, action Ask for agenda, tone Friendly -> `Hi! Sure, pwede. Ano ba ang agenda natin bukas ng 3 PM? 😊`. Coherent, asks for the agenda; it also says "Sure, pwede", which agrees before asking.
- **Option switching (the reported bug) works on device.** With a confirmation staged, tapping a different action replaced the staged choice (Ask for agenda -> Suggest another time) and tapping a different tone replaced the staged tone (Friendly -> Concise); the "Check before Akma writes" card followed each change ("Suggest another time · Concise") and drafting still needed the separate **Write reply** tap.
- **Analyze is now instant** (no model call); the intent card shows the deterministic category and "Not classified. Showing general replies."
- **Memory after load (post-run, not peak):** `dumpsys meminfo` TOTAL PSS 1,513,936-1,526,151 kB, RSS about 1.61-1.62 GB, native heap about 439 MB. No low-memory kill, ANR or crash was seen in the log during the generations.
- **Owner report:** the team lead reported that the tested flows worked as expected. That statement is recorded here as reported; its details (languages, drafts) were not independently captured.

## NOT MEASURED / NOT TESTED

- Model initialization milliseconds and first-run copy+verify time (the log buffer had already rotated; the model was usable about 3 min after "Try again", including human delay).
- A complete English journey and a complete Filipino journey driven by me: the USB connection dropped repeatedly and the handset was then unplugged. English and Filipino quality are therefore covered only by the desktop gate ([gemma4-e2b-filipino-gate.md](../gemma4-e2b-filipino-gate.md)) and the owner report.
- Native-speaker review of Filipino/Taglish drafts (not recorded).
- Thermal behaviour over repeated drafts, peak memory, XOS 10 background freeze, 120 Hz frame budget, punch-hole insets.
- The floating overlay (the bubble was switched on by a person; I did not exercise it), and overlay permission flow.
